# 문제 정의서

> **버전:** v2.0 (2026-10-14)
> **정본:** 제품·수용 계약은 `SPEC.md` v3.0, 도메인 개체·관계·근거는 `docs/ontology.yaml`을 따른다.
> **발표 정합성:** `docs/presentation/발표자료.pptx` 2~10쪽

## 1. 문제 진술

**개인투자자는 여러 투자 정보를 접해도 서로 다른 전망과 위험을 일관된 기준으로 비교해 포트폴리오 비중으로 연결하고, 그 비중이 결정된 이유를 확인하기 어렵다.** [SUR-01, SUR-02, SUR-11, LOG-001, LOG-003]

문제는 투자정보의 단순한 부족이 아니다. 조언 또는 시장 정보를 추가로 확인한 뒤에도 정보를 비교해 최종 판단을 마무리하고, 그 판단 근거를 추적하는 과정이 어렵다는 데 있다.

## 2. 대상 사용자와 관찰 근거

주요 대상은 투자 조언을 받은 뒤 추가 정보를 확인하지만 비교와 최종 판단에 어려움을 겪는 개인투자자다. 설문은 2026년 9월 16~30일 10명을 대상으로 했으므로, 이를 모든 개인투자자에게 일반화하지 않는다.

| 사례 | 관찰 | 문제 정의에서의 의미 |
|---|---|---|
| R3 | 지인 조언을 일부 실행했고, 의견에 모두 동의하지 못해 뉴스·시황을 며칠 확인함 | 추가 확인 뒤에도 판단이 끝나지 않을 수 있음 [SUR-01, SUR-02] |
| R9 | 의심 정보를 다른 출처와 교차확인함 | 정보 비교가 항상 결론을 보장하지는 않음 [SUR-11] |
| R7 | 의심 정보를 공시로 확인해 빠르게 판단함 | 모두가 같은 어려움을 겪는다고 주장하지 않음 [SUR-10] |
| R6 | 유튜브 조언을 ‘귀찮아서’ 실행하지 않음 | 단순 미실행은 핵심 문제의 직접 근거로 쓰지 않음 [SUR-01, LOG-002] |

## 3. 해결해야 할 과제

1. 기준시점에 실제 이용 가능했던 자료만 사용해 미래 정보 유입 없이 투자 신호를 만든다.
2. STABLE의 10거래일 수익률 경로와 검증된 증권사 리포트 전망을 결합하고, 종목·섹터 상한, 현금, 거래비용 등 위험 제약 아래에서 비중을 계산한다.
3. 종목 선정, 비중, 리포트 근거, 위험 제약 및 불확실성을 외부 사실은 원문 출처로, 계산 사실은 실행 기록으로 연결한다.
4. 모든 설명 주장을 검증해 출처 없는 주장, 수치·날짜·기간·인과가 왜곡된 주장, 미검증 주장을 공개하지 않는다.

## 4. 제공 가치와 사용 형태

개미구조대는 LLM이 비중을 정하는 서비스가 아니다. 재현 가능한 코드가 STABLE 경로, 리포트 신호 및 위험 제약으로 포트폴리오를 최적화하고, AI 에이전트는 리포트 수집·설명 생성·주장 검증을 담당한다.

사용자에게는 기준시점이 표시된 **일방향 포트폴리오 및 근거 보고서**를 제공한다. 보고서는 종목 선정과 비중 결정 이유, 사용 리포트의 원문 출처, 제약·거래비용의 영향, 모델 한계와 자료 부족 여부를 확인 가능하게 해야 한다. 대화형 챗봇이나 후속 질문 기능은 이번 범위에 없다.

이는 투자 판단을 대신하거나 수익을 보장하는 서비스가 아니라, 결정 근거를 재현·검토할 수 있게 하는 서비스다.

## 5. 검증할 가설

- **H1 — 포트폴리오 성과:** STABLE, 리포트 신호, 위험 제약을 결합하면 STABLE 단독·부분 결합·동일가중 대비 위험 대비 성과 또는 집중 위험을 개선할 수 있다. 이는 미검증 가설이다. [LOG-021]
- **H2 — 설명 효용:** 리포트 원문과 실제 최적화 실행 기록에 연결된 설명은 종목 선정·비중 결정에 대한 정확한 이해를 도울 수 있다. 이 또한 미검증 가설이다. [LOG-005, LOG-022]

H1은 동일 종목군·기간·거래조건에서 `EW`, `STABLE`, `STABLE+Risk`, `STABLE+Report`, `Full`의 다섯 비교군을 10개 오프셋과 왕복 30bps/60bps 조건으로 평가한다. Sharpe, 최대낙폭, 변동성, turnover, 종목·섹터 집중도를 함께 기록한다. [SPEC §9]

## 6. 범위와 비범위

| 범위 | 비범위 |
|---|---|
| 국내 대형주의 시점별 시세·섹터·증권사 리포트 수집 및 구조화 | 대화형 챗봇 및 후속 질문 |
| STABLE 경로 추론, 리포트 신호 결합, 재현 가능한 최적화 | 실제 주문 연동·자동 매매 |
| 종목·섹터 상한, 현금, 거래비용, 기존 보유 오프셋을 반영한 위험 관리 | 개인별 위험성향 평가·맞춤형 투자자문 |
| 근거 보고서 생성, 주장 검증, 검증된 버전만 일방향 게시 | 수익 보장·확정적 예측·리포트 원문 무단 재배포 |
| 과거 시점 백테스트와 오류 추적 | 무제한 웹 수집·결제·구독·개인화 알림 |

공개 전 리포트 이용허락·저작권·금융규제 적용 여부를 확인한다. 면책 문구만으로 이를 충족했다고 보지 않는다. [LOG-024, LOG-025]

## 7. 완료·안전 기준

1. 자료의 실제 이용 가능 시점이 기준시점과 부합하고, 미래 정보 유입은 0건이다.
2. 사용 리포트는 종목·출처·원문 버전·이용 가능 시점에 100% 연결된다. 확인이 부족한 신호는 제외한다.
3. 동일 스냅샷·모델·시드·설정에서는 경로, 비중, 게시 승인 판정이 재현된다.
4. 비중은 현금을 포함해 합계 1이며 롱온리·종목 상한·섹터 상한을 위반하지 않는다. 해가 없으면 제약을 임의로 완화하지 않는다.
5. 모든 공개 주장은 판정·사유를 가지며, `reject`·미판정·검증 실패·핵심 수치 오류가 남은 보고서는 게시하지 않는다.

상세 수용 기준과 시험 방법은 `SPEC.md`의 FR-01~FR-09, AC-01a~AC-09f를 따른다. 계약 충족은 초과수익이나 투자 안전성을 뜻하지 않으며, 성과 가설은 별도 백테스트로 판정한다.
