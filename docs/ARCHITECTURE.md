# 최종평가 위협 모델 (오프라인 기준점 범위)

## 데이터 흐름 및 신뢰 경계

사용자 성향·메모 → 수식 제안 CLI → AST 수식 검사·진단 → 사용자 확정 → 포트폴리오 계산
외부 PDF → 구조화 CLI → 검증된 컨센서스 → 순위·비중 계산 → 설명 CLI → 독립 검증 → 게시/로컬 대체
실행 요청·중간 결과 → 로컬 추적 로그 → 팀원 비밀/개인정보 검토 → 공개 평가 증빙

사용자 자유 입력, 외부 PDF, LLM 응답, CLI 인증 상태는 비신뢰 경계다. 포트폴리오 수치의 권위는 계산 엔진에 있고 LLM의 텍스트는 비중을 변경하지 않는다.

| ID | 자산 | 진입점 | 공격자 목표·영향 | 현재 방어 | 평가 ID |
|---|---|---|---|---|---|
| T1 | 로컬 프로세스·계산 무결성 | 직접 수식·생성된 수식 | 임의 코드·속성 접근·비유한 값으로 계산 오염 (높음) | AST 허용 목록, 실제 점수 검사, 사용자 확정 | A01, A02, A03 |
| T2 | 사용자 의도·수식 안전성 | 사용자 자유 메모 | 지시 우선순위 탈취로 금지 수식 선택 (높음) | 메모는 참고 자료, CLI 도구 제한, 코드 검사 및 대체 | A02 (악성 출력 대역) |
| T3 | 투자 설명 신뢰성 | 설명·검증 모델 반환 JSON | 출처 위조·판정 누락·경고 우회로 미검증 설명 게시 (높음) | 근거 ID 허용 목록, 인용 검사, 모든 주장 판정 요구, 실패 시 로컬 대체 | A04–A07 |
| T4 | 개인정보·인증 정보·원문 | 로그·외부 PDF | 공개 저장소에 민감 정보 유출 (높음) | 기본 자유 텍스트 제외, 평가용 마스킹 및 사람 검토; 원문 비공개 | 기존 test_kr_trace, 공개 전 검토 |

OWASP LLM01(프롬프트 인젝션), LLM05(출력 처리), LLM02(민감정보 노출) 관련. A01–A07은 실제 코드 경계를 호출하는 합성 공격/결함 주입이며 라이브 LLM 공격 성공률을 의미하지 않는다. 외부 PDF의 간접 인젝션과 허위 비중·수익 보장에 대한 실제 의미 검증은 별도의 라이브 평가가 필요하다.

## 합격 판정

각 공격의 성공 조건은 evals/evalset.jsonl에 명시한다. 실제 공격 성공 / 전체 공격 건수로 ASR을 계산한다. 실행 예외 등 결과 불명은 성공/차단으로 간주하지 않고 ASR을 미확정으로 둔다. 정상 통과율과 함께 보고한다. 평가 자료는 고정 후 제품 개선 회차에 따라 변경하지 않는다.
