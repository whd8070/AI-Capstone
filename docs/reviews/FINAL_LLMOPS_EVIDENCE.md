## 기준점과 회차

원래 36건 유지, 실사용 회귀 2건과 공격 7건을 같은 evalset에 추가. 별도 기존 수식 24건 및 골든을 유지한다. 기준점 커밋에서 동일한 데이터·코드로 기준점 1/3, 2/3, 3/3을 기록한다. 정상/경계/실패/금지/공격 통과율, 공격 성공률 및 미확정 수를 함께 본다. 이 결정적 시험은 라이브 LLM 정확도나 전체 GUI 성능 측정이 아니다. 실제 시간 비교는 같은 데이터·모델 설정 및 캐시 조건의 재시연으로 검증한다.

회차별 단일 가설, 동일 evalset 및 코드 판정, 기존 골든 유지. 커밋 메시지와 change는 R번호 | 대상: 케이스 id | 가설: 한 문장 형식을 일치시킨다. 개별 수정은 기준점 측정 이후 시작하며 악화/미달 시 기각·revert 사유를 남긴다. 팀원 승인/검토는 임의 기록하지 않는다.

AI 설명의 거부 원인은 주장 ID만 기록되어 확인 불가. 이후 검증 reason_code/근거 ID와 실제 주장 대응을 확인하고, 고정 수치 템플릿과 AI 해석 분리, 실패 주장만 수정하는 가설을 별도로 검증한다. 검증 기준을 완화하거나 로컬 설명을 AI 승인으로 기록하지 않는다. 수식 제안의 Codex 지원과 UI 재배치는 회귀 회차 이후 별도 기능 작업으로 관리한다.
