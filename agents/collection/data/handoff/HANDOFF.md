## 파일
- `forecasts.jsonl` / `forecasts.csv`: **간단 형식.** 리포트 1건 = 1행 {report_date, company, target_date(전망 시점), target_price(전망 가격), rationale(근거)} + 추적용 broker·opinion·nid. target_date = report_date + 목표가 기간. 기간이 리포트에 없으면 12개월로 가정하고 horizon_assumed=true. 목표가 없는 리포트는 제외. csv의 rationale은 ' | '로 이어 붙임.
- `reports_compact.jsonl`: 리포트 1건 = 1줄. 근거·리스크는 원문 인용이 검증된 것만 남김. 근거 원문은 (nid, page)로 추적 가능.
- `daily_consensus.csv`: 리포트가 나온 날마다 한 행. 그날까지 공개된 리포트만 사용(미래 정보 없음).

## 사용 규칙 (중요)
- 날짜는 리포트 공개일. 시각 정보가 없으므로 **T일 행은 T일 장 마감 이후 의사결정에만** 사용한다.
- 컨센서스는 공개일 기준 직전 90일 안의 증권사별 최신 리포트로 계산한다. 한 증권사가 여러 번 내도 1표.
- 리포트가 없는 날은 행이 없다. 일별 시계열로 쓸 때는 직전 값을 앞으로 채우되(forward fill), 뒤로 채우지 않는다.
- 목표가·투자의견은 네이버 API(manifest) 값. LLM이 읽은 값과 다르면 quality.flags에 target_mismatch.
- 예외: 네이버 목표가가 리포트 본문과 다르고 본문 숫자가 코드로 확인되면 본문 값을 쓴다 (target_price_source / tp_source = report_text, 원래 네이버 값은 tp_naver).

## daily_consensus.csv 칼럼
- n_reports_today / brokers_today: 그날 나온 리포트 수·증권사
- tp_up_today / tp_down_today: 그날 직전 대비 목표가를 올린/내린 증권사 수
- n_brokers_90d: 컨센서스에 들어간 증권사 수
- tp_median / tp_mean / tp_min / tp_max / tp_std: 목표가 분포(의견 분산 = tp_std, max-min)
- buy_ratio: 의견이 있는 증권사 중 매수 계열 비율(opinion_norm 기준)
- nids_today: 그날 리포트 nid → reports_compact.jsonl에서 근거 조회
