# 개미구조대 — KR MOM + PAIR + REPORT

> 아주대학교 2026학년도 2학기 AI 캡스톤디자인 · **국내 주식 포트폴리오 분석 MVP** · [웹 상세 사용법](src/diffusion/README_KR_REPORT_WEB.md)

## MVP 사용자 가이드

처음 서비스를 접하는 학생이 **별도 계정 없이 로컬 웹을 실행하고**, 기존 데이터로 **포트폴리오·백테스트 결과를 확인**할 수 있도록 작성한 안내입니다. 리뷰 대상 버전은 `main` 브랜치입니다.

### 1. 서비스 소개

| 구분 | 내용 |
| --- | --- |
| 팀 번호 | **확인 필요** — 현재 저장소 문서에 기재되어 있지 않음 |
| 팀 이름 | **개미구조대** (박종인, 허준영) |
| 서비스 이름 | **KR MOM + PAIR + REPORT** |
| 대상 사용자 | 국내 주식 투자 판단을 데이터로 비교·검토하려는 개인 및 금융·AI 분석에 관심 있는 학생 |
| 접속 방식 | **로컬 Streamlit 웹** — 설치한 컴퓨터에서 `http://127.0.0.1:8501` |
| 소스 코드 | [GitHub 저장소](https://github.com/whd8070/AI-Capstone) |

**해결하려는 문제:** 모멘텀이나 AI 예측 하나만으로 투자 결정을 내리면 순위 변화, 리스크, 증권사 전망이 비중에 어떻게 반영됐는지 파악하기 어렵습니다. 이 MVP는 **MOM(모멘텀) + PAIR(확산모델 조건부 비교 순위) + REPORT(증권사 리포트 컨센서스)**를 결합하고, 기존 방식 대비 종목 순위·포트폴리오 비중·백테스트 결과를 비교하도록 돕습니다.

**이번 MVP에서 사용 가능한 핵심 기능**

1. **기간 백테스트:** 20슬리브 전략에서 REPORT 적용 전·후 수익곡선(NAV), Sharpe, MDD, 연환산 수익률·변동성을 비교합니다.
2. **특정 매수일 포트폴리오:** 과거 실제 KRX 매수일을 지정해 44개 종목의 상대 순위, 투자 비중과 근거, 20거래일 생성 시나리오를 확인합니다. 별도 AI 계정 없이 **데이터 기반 로컬 해설**을 사용할 수 있습니다.
3. **신규 리포트 수집(선택):** 증권사 PDF를 수집하고, 연결된 **Codex 또는 Claude CLI**로 구조화·검증해 컨센서스를 갱신할 수 있습니다. **포트폴리오의 AI 해설·검증**도 선택 사항입니다.

> 현재 작동하는 MVP는 **투자 의견 정교화**와 연결된 국내 주식 분석 프로토타입입니다. CFP형 종합 자산관리 및 금융정책·공공지원 맞춤 탐색은 전체 기획 도메인이며, 이번 MVP에 모두 구현된 기능은 아닙니다. **실제 주문·자동매매 기능은 없습니다.**

### 2. 실행 및 접속 방법

**지원·검증 범위:** Windows 11(64비트) 권장, macOS(Apple Silicon/Intel) 설치 스크립트 제공. Python **3.11** 기반이며 GPU는 필요하지 않습니다. Windows 로컬 설치·실행 경로를 중심으로 안내하며, **macOS 전체 백테스트의 실기기 검증은 별도로 확인이 필요**합니다. 인터넷 연결은 초기 설치, 시세 다운로드, 신규 리포트 수집, 선택적 CLI 인증에 필요합니다.

**처음 설치 — Windows 11 (PowerShell)**

아래 세 줄을 PowerShell에 순서대로 입력합니다. 스크립트가 Git/Python 3.11 확인·설치, `main` 브랜치 복제, 가상환경·웹 패키지 설치, 웹 실행을 진행합니다.

```powershell
$bootstrap = Join-Path $env:TEMP 'AI-Capstone-bootstrap.ps1'
Invoke-WebRequest 'https://raw.githubusercontent.com/whd8070/AI-Capstone/main/bootstrap_windows.ps1' -OutFile $bootstrap
powershell.exe -NoProfile -ExecutionPolicy Bypass -File $bootstrap
```

**처음 설치 — macOS (터미널)**

```bash
curl -fL https://raw.githubusercontent.com/whd8070/AI-Capstone/main/bootstrap_mac.sh -o /tmp/ai-capstone-bootstrap-mac.sh
bash /tmp/ai-capstone-bootstrap-mac.sh
```

Mac에서 Apple 명령줄 도구 설치 창이 나타나면 설치를 마친 뒤 위 명령을 **다시 실행**합니다. Homebrew가 없으면 설치 승인을 요청할 수 있습니다. 첫 설치 경로는 두 운영체제 모두 사용자 홈의 `AI-Capstone` 폴더입니다.

**이미 설치한 사용자 — 이후 실행만**

Windows PowerShell:

```powershell
cd "$HOME\AI-Capstone"
.\run_windows.cmd
```

macOS 터미널:

```bash
cd "$HOME/AI-Capstone"
bash ./run_mac.sh
```

이미 다른 경로에 저장소를 복제했다면 해당 **저장소 루트**로 이동해 실행합니다. 두 재실행 스크립트는 기존 `src/diffusion/.venv`를 사용하며 Git·Python·패키지를 매번 다시 설치하지 않습니다. 초기 설치를 복구하려면 Windows에서 `.\start_windows.cmd`, macOS에서 `bash ./start_mac.sh`를 실행합니다.

**접속:** 웹이 실행되면 같은 컴퓨터의 브라우저에서 **http://127.0.0.1:8501**을 엽니다. 이 주소는 **공개 배포 URL이 아닌 본인 컴퓨터의 로컬 주소**이므로, 리뷰어는 각자 설치해야 합니다. 종료는 웹을 실행한 터미널에서 `Ctrl+C`입니다.

**코드 업데이트:** 실행 중인 웹을 종료하고 저장소 루트에서 `git pull origin main` → 운영체제별 재실행 명령 순으로 진행합니다. 의존성 변경 시에만 `start_windows.cmd` 또는 `start_mac.sh`를 사용합니다.

### 3. 핵심 기능 체험 순서

**가정할 역할:** 국내 주식 포트폴리오의 비중이 증권사 리포트 반영 전후 어떻게 달라지는지 검토하는 개인 투자자.

**체험 목표:** 샘플 기간·매수일을 입력해 REPORT 반영 전후 순위·비중·성과를 확인하고, 필요하면 AI 해설과 신규 리포트 수집까지 체험합니다. **처음에는 추가 계정이 필요 없는 2번 탭부터 진행하는 것을 권장합니다.**

#### 체험 A — 특정 매수일 포트폴리오 (기본·권장)

1. 웹 왼쪽 **순위 신호 배합**에서 `PAIR 비율 = 0.50`, `REPORT 비율 = 0.50`을 선택합니다. 두 값은 **최종 투자비중의 단순 가중평균 비율이 아니라 순위 신호 결합 비율**입니다.
2. 상단 **「특정 매수일 포트폴리오」** 탭을 엽니다.
3. `매수일 (실제 KRX 거래일, 과거)`을 **2026-11-05**로 설정합니다. 이는 기본 포함 리포트의 최신 날짜(2026-11-04) 다음 거래일을 활용한 예시입니다.
4. `포트폴리오 설명 방식`에서 **「데이터 기반 로컬 해설 (LLM 호출 없음)」**을 선택합니다.
5. **「포트폴리오 생성 (수치 먼저 표시)」**를 누릅니다. 시세 다운로드·모델 추론·위험 최적화가 수행되므로 첫 계산에 시간이 걸릴 수 있습니다.
6. 투자비중·전후 순위 표, 리포트 근거와 생성 시나리오를 확인합니다. **「실제 편입 종목만 보기」** 체크를 해제하면 편입 비중이 0%인 종목까지 포함해 전체 44종목을 확인할 수 있습니다.
7. **「최종·기존 포트폴리오 CSV」**, **「설명 TXT」**를 내려받아 결과를 확인합니다.

`K=128`, `seed=0`은 재현성을 위해 고정되어 있습니다. 과거 거래일과 유효 리포트 여부를 확인해야 하므로 날짜에 따라 데이터 가용성이 다를 수 있습니다.

#### 체험 B — 기간 백테스트 (기본)

1. 상단 **「기간 백테스트」** 탭으로 이동합니다.
2. 예시: `시작 신호일 = 2026-10-27`, `종료 평가일 = 2026-11-04`, `PAIR = 0.50`, `REPORT = 0.50`. 짧은 기능 확인에는 **「처음 5개 신호만 점검 (정식 백테스트 아님)」**을 체크합니다.
3. **「백테스트 실행 (별도 프로세스)」**를 누르고 **「이전/진행 중인 작업」**의 상태·진행률을 확인합니다.
4. 완료되면 **REPORT 적용 전후 NAV 그래프**, 성과 지표 표, **날짜별 순위·비중 변화**를 비교하고 **「전체 날짜별 순위·비중 CSV」**를 내려받습니다.
5. 정식 기간 성과를 비교하려면 **5개 신호 점검 체크를 해제**하고 유효 데이터가 있는 시작·종료일로 다시 실행합니다.

백테스트는 매 신호일 **종가 정보로 다음 거래일 시가에 신규 슬리브를 체결**하는 20슬리브 시뮬레이션입니다. 짧은 점검 실행 결과를 정식 성과로 해석하지 마세요.

#### 체험 C — Claude/Codex 해설 (선택·추가 계정 필요)

1. 먼저 **「리포트 신규 수집 (선택)」** 탭의 **「AI 모델 연결하기」**에서 Codex/Claude 상태를 확인합니다.
2. Windows 로컬 실행이라면 해당 모델의 **「설치 창 열기」 → 「로그인 창 열기」 → 「연결 상태 다시 확인」** 순으로 설정합니다. macOS에서는 화면의 수동 설치·로그인 안내를 사용합니다. **CLI 자체 로그인**이 필요하며 VS Code 확장 로그인만으로는 보장되지 않습니다.
3. **「특정 매수일 포트폴리오」** 탭에서 로그인 확인된 설명 모델을 선택해 **먼저 수치 포트폴리오를 생성**합니다.
4. 이어서 **「AI 설명 생성·독립 검증 (모델 추론 재실행 없음)」** 버튼을 눌러 생성 설명과 검증 결과를 확인합니다. 실패·미승인 시 AI 설명을 표시하지 않고 **로컬 해설로 대체**합니다.

AI 설명은 선정 이유·리포트 근거·비중 결정·위험관리·불확실성의 5개 영역을 다루며, **추론 수치와 비중 자체를 바꾸지 않습니다.** CLI 연결 및 호출 가능한 계정·사용량이 필요할 수 있습니다.

#### 체험 D — 새로운 증권사 PDF 수집·구조화 (선택·추가 계정 필요)

1. **「리포트 신규 수집 (선택)」** 탭에서 **연결 상태를 확인**한 뒤, `신규 리포트를 구조화할 LLM`을 선택합니다.
2. `리포트 수집 마감일`을 기존 컨센서스 최신 날짜(기본 데이터는 **2026-11-04**)보다 뒤로 설정합니다. 예: **2026-11-10**. 화면의 수집 대상·이미 다운로드·구조화 대기 건수를 확인합니다.
3. `수집 단계`에서 **「PDF 다운로드 + 선택한 LLM 구조화 + 컨센서스 반영」**을 선택합니다. **「PDF만 다운로드」**는 파일만 저장하며 투자 신호를 갱신하지 않습니다.
4. 구조화 건수·사용량 상한을 확인하고 **「수집 범위·선택한 CLI 사용량·시점 제한을 확인했습니다」**에 체크한 후 **「선택한 단계 실행」**을 누릅니다.
5. 완료·오류·구조화 대기 상태를 확인합니다. **모든 필요한 추출이 완료되어 컨센서스가 갱신된 후** 2번 탭에서 해당 매수일의 포트폴리오를 다시 계산합니다.

**실행 전 조건이 맞지 않으면 버튼을 눌러도 실행되지 않으며 화면에 사유가 표시됩니다.** 새로운 수집 기간이 없거나 CLI 로그인 미완료, 확인 체크 누락 등이 원인일 수 있습니다. **자동 포트폴리오 계산**까지 선택했다면 매수일은 반드시 수집 마감일보다 늦어야 합니다. 기존 컨센서스만 체험할 경우 이 단계는 건너뛰어도 됩니다.

### 4. 기대 결과 및 확인 방법

| 체험 | 정상 실행 시 확인할 것 | 재확인·재실행 |
| --- | --- | --- |
| A: 매수일 포트폴리오 | 종목별 REPORT 적용 전·후 순위/비중, 편입 종목 표, 로컬 해설, 20거래일 생성 시나리오, CSV/TXT 다운로드 | 날짜 또는 왼쪽 PAIR/REPORT 비율을 바꾸고 **포트폴리오 생성** |
| B: 기간 백테스트 | 진행 상태가 **계산 완료**로 바뀐 뒤 NAV 비교 그래프, Sharpe·MDD 등, 날짜별 CSV | 기간·비율을 바꿔 새 작업 실행; 진행 중이면 작업 상태/로그 확인 |
| C: AI 해설 | 수치 포트폴리오를 유지하면서 AI 문장과 **독립 검증 승인(PASS)** 또는 실패·로컬 대체 사유 표시 | 로그인 상태·근거를 점검하고 별도 AI 설명 버튼 재실행 |
| D: PDF 수집 | PDF/구조화 건수·결과 상태, 완료 시 로컬 컨센서스 오버레이 갱신 | **구조화 대기·오류** 확인 뒤 같은 조건으로 재실행; 성공한 캐시는 재사용 |

백테스트 작업·로그는 `src/diffusion/results/kr_report_dashboard/`에 저장됩니다. AI 해설의 로컬 검증 상태 `LOCAL_RULE_ONLY`는 **독립 LLM 의미 검증 PASS가 아님**을 의미합니다. 사용자가 설정을 바꿔 다시 실행하면 이전 결과를 삭제하지 않고 작업·캐시를 활용할 수 있습니다.

### 5. 계정·샘플 데이터·환경·제한 사항

- **계정/접근 권한:** A·B 체험은 웹 계정과 Claude/Codex 로그인 없이 가능합니다. C·D는 선택한 **Codex 또는 Claude CLI** 설치·로그인, 계정 이용 권한/사용량이 필요합니다. 비밀번호·로그인 토큰은 웹에 입력하지 않습니다.

## 확정 도메인

### 1. CFP형 종합 자산관리

#### 개요

사용자의 현재 재무 상태와 생애 목표를 종합적으로 파악하고 소비, 저축, 투자, 위험관리, 세금 및 은퇴처럼 서로 연결된 재무 의사결정을 지원하는 도메인입니다.
단순한 금융상품 추천이 아니라 사용 가능한 여유 자금, 투자 기간, 유동성 필요와 허용 가능한 변동성을 함께 고려해 실행 가능한 자산관리 계획을 세우는 것을 목표로 합니다.

#### 문제 정의

- 개인은 소득, 지출, 부채, 보유 자산과 미래 목표를 하나의 계획으로 연결하기 어렵습니다.
- 투자 가능한 여유 자금과 비상 자금을 구분하지 못하거나 목표 시점과 위험 감수 수준에 맞지 않는 자산을 보유할 수 있습니다.
- 자산 배분, 리밸런싱, 세금, 보험과 은퇴 준비가 서로 영향을 주지만 이를 통합적으로 판단하기 어렵습니다.
- 전문가의 종합 자산관리 서비스는 비용과 접근성 때문에 지속적으로 이용하기 어려울 수 있습니다.

#### 주요 사용자

- 자산관리를 처음 체계화하려는 사회초년생과 개인투자자
- 소득과 자산이 늘면서 투자, 주거, 결혼, 교육 및 은퇴 등 여러 재무 목표를 함께 관리해야 하는 개인

구체적인 우선 사용자는 인터뷰를 통해 문제의 빈도와 중요도를 확인한 뒤 결정합니다.

#### 고려할 사용자 조건

- 소득, 고정비와 변동비 등 월별 현금흐름
- 예금, 투자자산, 연금과 부채 등 자산·부채 현황
- 비상 자금과 실제로 투자 가능한 여유 자금
- 주거, 결혼, 교육 및 은퇴 등 재무 목표와 목표 시점
- 투자 가능 기간과 중간에 자금이 필요할 가능성
- 손실 감수 수준과 허용 가능한 변동성
- 투자 경험, 금융 지식과 선호하는 관리 방식
- 세금, 보험, 상속·증여 등 추가로 고려할 조건

#### 핵심 기능

1. **재무 진단**: 현금흐름, 자산, 부채와 재무 목표를 구조화하고 현재 상태를 요약합니다.
2. **여유 자금 산정**: 생활비, 비상 자금과 단기 지출 계획을 고려해 투자에 활용할 수 있는 금액을 구분하도록 돕습니다.
3. **목표 기반 자산 배분**: 목표 금액, 투자 기간, 유동성 필요와 허용 변동성에 따라 자산군별 배분 방향과 그 이유를 설명합니다.
4. **시나리오 비교**: 저축액, 투자 기간, 기대수익률 또는 변동성 조건이 달라질 때 목표 달성 가능성과 위험이 어떻게 변하는지 비교합니다.
5. **포트폴리오 점검과 리밸런싱**: 현재 자산의 편중, 중복, 유동성과 목표 간 불일치를 확인하고 정기적인 점검 기준을 제시합니다.
6. **현금흐름과 부채 관리**: 소비, 저축과 부채 상환이 장기 목표에 미치는 영향을 보여 주고 우선순위를 정리하도록 돕습니다.
7. **세금 이슈 확인**: 투자와 자산 이전 과정에서 확인해야 할 세금 항목과 시점을 안내하고, 구체적인 판단이 필요한 경우 전문가 상담으로 연결합니다.
8. **위험관리와 생애 재무계획**: 보험 보장, 비상 상황, 은퇴와 주요 생애 사건이 전체 재무계획에 미치는 영향을 점검합니다.

#### AI 활용 방향

- 대화를 통해 흩어진 재무 정보를 구조화하고 빠진 정보를 질문합니다.
- 사용자의 목표와 제약 조건에 맞는 대안을 비교해 설명합니다.
- 제안에 사용된 조건과 가정을 표시하고, 조건이 바뀔 때 결과가 어떻게 달라지는지 보여 줍니다.
- CFP 전문가가 제공하는 종합 재무설계의 접근성을 높이되, AI가 보조할 수 있는 영역과 전문가의 판단이 필요한 영역을 구분합니다.

#### 검증 항목

- 사용자가 자신의 전체 재무 상태를 파악하고 목표별 계획으로 연결하는 데 실제로 어려움을 겪는지 확인합니다.
- 단순한 상품 추천보다 여유 자금, 투자 기간과 위험 수준을 반영한 설명을 원하는지 확인합니다.
- 선택의 근거와 시나리오를 함께 제공하는 방식이 계획의 이해와 지속적인 실행에 도움이 되는지 검증합니다.

### 2. 투자 의견 정교화

#### 개요

사용자가 특정 주식, ETF 또는 투자 아이디어에 대해 가진 의견을 근거와 반대 관점이 포함된 투자 논리로 발전시키도록 돕는 도메인입니다.
종목 추천이나 매매 신호 제공보다 사용자가 일관된 판단을 내리고 그 과정을 사후에 회고할 수 있도록 지원하는 데 초점을 둡니다.

#### 문제 정의

- 개인투자자는 뉴스, 공시, 리포트와 커뮤니티 등 많은 정보를 자신의 투자 판단과 연결해 체계적으로 정리하기 어렵습니다.
- 투자 아이디어가 있어도 매수·보유·매도 근거, 기대 조건, 위험 요인과 투자 가설을 철회할 조건을 명확히 세우지 않는 경우가 많습니다.
- 기존 믿음을 뒷받침하는 정보만 선택하거나 단기 가격 변화에 따라 판단 기준을 바꾸기 쉽습니다.
- 판단 과정이 기록되지 않으면 투자 결과가 나온 뒤에도 무엇을 잘했고 무엇을 개선해야 하는지 구분하기 어렵습니다.

#### 주요 사용자

- 주식이나 ETF를 직접 분석하고 선택하는 개인투자자
- 투자 아이디어는 있지만 이를 논리적으로 정리하거나 반대 근거까지 검토하는 데 어려움을 겪는 개인투자자

#### 핵심 기능

1. **투자 의견 구조화**: 자연어로 작성한 생각에서 투자 대상, 목적, 기간, 핵심 근거, 기대 요인과 위험 요인을 구분합니다.
2. **근거와 사실 확인**: 사용자의 주장, 객관적 사실, 추정과 감정적 판단을 구분하고 확인이 필요한 정보와 출처를 제시합니다.
3. **반대 관점 질문**: 근거가 부족하거나 충돌하는 부분, 고려하지 않은 변수와 반대 시나리오를 질문해 의견을 보완하도록 돕습니다.
4. **투자 가설과 철회 조건 설정**: 투자 의견이 유효한 조건과 재검토하거나 철회해야 할 조건을 투자 전에 기록합니다.
5. **대안 비교**: 특정 투자 대상을 현금 보유, 유사 상품 또는 다른 자산군과 비교해 기회비용과 위험을 검토합니다.
6. **투자 기록과 회고**: 투자 당시의 정보와 판단을 보존하고 실제 결과와 비교해 과정의 적절성, 반복되는 실수와 편향 가능성을 점검합니다.

#### AI 활용 방향

- 투자 의견을 요약하고 구조화하며 반대 관점과 추가 확인 질문을 생성합니다.
- 공개된 금융 정보와 사용자가 제공한 자료를 활용할 경우 출처, 기준 시점과 불확실성을 함께 표시합니다.
- 사용자의 최종 판단을 대신하기보다 사고 과정을 명료하고 검증 가능하게 만드는 보조 도구를 지향합니다.

#### 검증 항목

- 개인투자자가 투자 의견을 체계적으로 작성하고 반대 관점까지 검토하는 과정에서 실제로 어려움을 겪는지 확인합니다.
- AI가 제공하는 질문과 구조가 투자 근거와 위험을 명확히 이해하는 데 도움이 되는지 검증합니다.
- 투자 전 판단 기록과 투자 후 회고의 연결이 반복되는 실수와 판단 편향을 발견하는 데 도움이 되는지 확인합니다.

### 3. 금융정책·공공지원 맞춤 탐색

#### 개요

사용자의 연령, 소득, 가구 상황, 자산과 재무 목표를 바탕으로 이용할 가능성이 있는 금융정책과 공공지원 제도를 찾아 이해하고 신청하도록 돕는 도메인입니다.
여러 기관에 흩어진 제도를 단순히 나열하는 것이 아니라 사용자 조건과 목표에 맞는 후보를 선별하고, 자격 조건, 혜택, 제한사항과 신청 절차를 비교해 설명하는 것을 목표로 합니다.

#### 문제 정의

- 청년 자산형성, 주거금융, 정책대출, 연금과 세제 지원제도가 여러 기관과 사이트에 흩어져 있어 한 번에 파악하기 어렵습니다.
- 제도마다 연령, 소득, 자산, 가구 구성과 거주지 등 자격 조건이 달라 자신이 대상인지 판단하기 어렵습니다.
- 유사한 제도의 혜택과 제한사항을 비교하거나 중복 가입 및 동시 이용 가능 여부를 확인하기 어렵습니다.
- 신청 기간, 필요 서류와 후속 절차를 놓쳐 이용할 수 있는 지원을 받지 못할 수 있습니다.
- 정책과 조건이 변경될 수 있어 과거 정보만으로 판단하면 잘못된 결정을 내릴 가능성이 있습니다.

#### 주요 사용자

- 청년 자산형성 및 주거 지원제도를 찾는 사회초년생
- 정책대출, 연금, 세제 혜택 등 재무 상황에 맞는 공공지원이 필요한 개인과 가구
- 여러 제도를 직접 검색하고 자격 조건을 비교하는 데 어려움을 겪는 사용자

#### 고려할 사용자 조건

- 연령, 거주지역과 가구 구성
- 소득, 자산, 부채와 고용 상태
- 주거, 결혼, 출산, 교육, 창업 및 은퇴 등 지원이 필요한 목적
- 가입 중이거나 이미 지원받고 있는 제도
- 신청 가능 기간과 자금이 필요한 시점
- 우대 조건, 제외 조건과 중복 이용 제한

#### 핵심 기능

1. **제도 후보 탐색**: 사용자의 조건과 목표를 바탕으로 이용 가능성이 있는 금융정책과 공공지원 제도 후보를 찾습니다.
2. **자격 조건 점검**: 충족한 조건, 확인이 필요한 조건과 제외 가능성이 있는 조건을 구분해 보여 줍니다.
3. **제도 비교**: 지원 내용, 금리, 납입 조건, 이용 기간, 의무사항과 제한사항을 동일한 기준으로 비교합니다.
4. **중복 가능성 확인**: 현재 이용 중인 제도와 새로운 제도의 중복 가입 또는 동시 이용 제한을 확인하도록 돕습니다.
5. **신청 절차 안내**: 신청 기간, 담당 기관, 공식 신청 경로와 필요 서류를 체크리스트로 정리합니다.
6. **변경사항 추적**: 사용자가 관심을 표시한 제도의 조건, 일정과 공고 변경사항을 확인할 수 있도록 지원합니다.
7. **재무계획 연결**: 제도 활용 여부가 사용자의 현금흐름, 부채 상환과 장기 재무 목표에 미치는 영향을 비교합니다.

#### AI 활용 방향

- 자연어로 입력한 사용자 상황에서 제도 탐색에 필요한 조건을 구조화하고 누락된 정보를 질문합니다.
- 여러 기관의 공식 자료에서 조건과 혜택을 추출해 사용자가 이해하기 쉬운 형태로 비교합니다.
- 추천 근거, 충족 여부, 확인하지 못한 항목, 공식 출처와 기준 시점을 함께 표시합니다.
- 최종 자격을 임의로 판정하지 않고 신청 가능성이 있는 후보와 사용자가 공식 기관에서 확인해야 할 절차를 안내합니다.

#### 검증 항목

- 사용자가 자신에게 적합한 금융정책과 공공지원 제도를 찾고 비교하는 데 실제로 어려움을 겪는지 확인합니다.
- 개인 조건에 따라 후보를 선별하고 자격 조건을 설명하는 방식이 탐색 시간과 이해 부담을 줄이는지 검증합니다.
- 공식 출처, 기준 시점과 불확실성을 표시하는 방식이 서비스 신뢰 형성에 충분한지 확인합니다.
- 제도 탐색 결과를 CFP형 재무계획과 연결하는 것이 사용자에게 추가적인 가치를 제공하는지 검증합니다.

## 세 도메인의 관계

CFP형 종합 자산관리는 사용자의 전체 재무 상태와 생애 목표를 기준으로 얼마를, 언제까지, 어느 정도의 위험으로 운용할지를 다룹니다.
투자 의견 정교화는 그 범위 안에서 특정 투자 대상이나 아이디어를 왜 선택하는지, 근거가 충분한지, 언제 판단을 바꿀지를 다룹니다.
금융정책·공공지원 맞춤 탐색은 사용자가 활용할 수 있는 제도와 혜택을 찾아 재무계획에 반영하도록 돕습니다.

예를 들어 금융정책·공공지원 맞춤 탐색에서 사용 가능한 주거 지원이나 정책대출을 확인하면, CFP형 종합 자산관리는 이를 현금흐름과 장기 목표에 반영하고 투자 의견 정교화는 그 범위 안에서 선택하려는 ETF나 주식의 투자 논리를 점검할 수 있습니다.
세 도메인은 독립적으로 문제와 가치를 검증하되, 장기적으로 하나의 개인 금융 의사결정 과정으로 연결할 수 있습니다.

## 공통 기반 기능

1. 사용자 목표와 제약 조건을 구조화하는 대화형 입력
2. 사용자가 직접 확인하고 수정할 수 있는 사용자 정보 관리
3. 제안에 사용한 데이터, 가정, 출처와 기준 시점 표시
4. 조건 변화에 따른 대안과 결과 비교
5. 의사결정 과정의 기록과 사후 회고
6. 개인정보 최소 수집과 민감정보 보호
7. 전문가의 판단이 필요한 상황 식별 및 상담 연계
8. 공식 정보의 변경 감지와 기준 시점 관리

## 금융·개인정보 보호 원칙

- 실제 개인정보, 계좌 정보와 거래 내역은 불필요하게 수집하거나 저장하지 않습니다.
- 사용자 인터뷰와 조사 자료는 익명화하며, 예시와 테스트에는 합성 데이터를 사용합니다.
- 금융 정보에는 출처와 기준 시점을 표시하고 최신성과 정확성을 검증합니다.
- 금융정책과 공공지원 정보는 공식 기관 자료를 우선하며 최종 자격과 신청 가능 여부는 해당 기관에서 확인하도록 안내합니다.
- AI의 결과를 확정적인 투자 권유, 수익 보장 또는 세무·법률 자문으로 제시하지 않습니다.
- 실제 금융상품 자문, 투자일임, 세무·법률 상담의 허용 범위와 필요한 자격은 별도로 검토합니다.
